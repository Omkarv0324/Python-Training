# Week 1 — Optional Homework (Core → Stretch → Bonus)

These are **optional** — the course is lecture/demo driven. Share with learners who want
hands-on practice. Solutions are in `solutions.md`.

---

## Session 1.1 — Intro, print, variables
- **Core:** Write a script that prints your name, your city, and "Learning Python!" on three lines.
- **Stretch:** Store those in variables first, then print them.
- **Bonus:** Recreate the startup banner with your own 4 checklist items.

## Session 1.2 — Numbers & math
- **Core:** Compute the area of a rectangle (width 7, height 3) and print it.
- **Stretch:** A bill is 84.50 with a 15% tip. Print the tip and total.
- **Bonus:** Given `seconds = 5000`, print it as minutes and leftover seconds using `//` and `%`.

## Session 1.3 — Strings & input
- **Core:** Ask for a first and last name; print the full name and its length.
- **Stretch:** Ask for a birth year; print the person's age in 2026.
- **Bonus:** Ask for a full name; print it reversed using slicing (`[::-1]`).

## Session 1.4 — Lists & tuples
- **Core:** Make a list of 4 tasks; append a 5th; print the list and its length.
- **Stretch:** Print the first and last task using indexing.
- **Bonus:** Store a point as a tuple `(x, y)`, unpack it, and print `x` and `y`.

## Session 1.5 — Dicts & sets
- **Core:** Make a dict for a book (title, author, year); print each with a loop.
- **Stretch:** Use `.get()` to safely look up a missing key with a default.
- **Bonus:** Given a list with duplicates, print the unique values using a set.
