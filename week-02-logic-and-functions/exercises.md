# Week 2 — Optional Homework (Core → Stretch → Bonus)

Optional practice to accompany the demo-driven sessions. Solutions in `solutions.md`.

## Session 2.1 — Decisions
- **Core:** Ask for a number; print whether it's positive, negative, or zero.
- **Stretch:** Grade a score (0–100) into A/B/C/D/F with `if`/`elif`/`else`.
- **Bonus:** Given `age` and `has_ticket`, print "entry allowed" only if both conditions pass.

## Session 2.2 — for loops & range
- **Core:** Print the numbers 1 to 10 using `range()`.
- **Stretch:** Sum all numbers from 1 to 100 with an accumulator.
- **Bonus:** Use `enumerate()` to print a numbered list of 4 tasks.

## Session 2.3 — while & comprehensions
- **Core:** Count down from 5 to 1 with a `while` loop, then print "Go!".
- **Stretch:** Build `[n*n for n in range(1, 11)]` and print it.
- **Bonus:** From a list of numbers, use a comprehension to keep only the evens.

## Session 2.4 — functions
- **Core:** Write `area(width, height)` that returns the area; call it twice.
- **Stretch:** Add a default parameter (e.g., `greet(name, greeting="Hello")`).
- **Bonus:** Write `is_even(n)` returning `True`/`False`; use it in a loop over 1..10.

## Session 2.5 — *args / lambdas / modules
- **Core:** Write `total(*args)` that returns the sum of any number of values.
- **Stretch:** Sort a list of `(name, age)` tuples by age using `sorted(key=lambda ...)`.
- **Bonus:** Put two functions in `myutils.py`, import them into another script, and call them.
